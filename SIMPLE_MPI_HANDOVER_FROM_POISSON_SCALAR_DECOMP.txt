================================================================================
6. libscalar_decomp API and role
================================================================================

Header:

  libscalar_decomp/include/scalar_decomp_library.h

Main equation form:

  div(F phi) - div(Gamma grad(phi)) + Sp phi = Su

where:
  F = faceFlux = rho u_f dot S_f, oriented owner -> neighbour / outward for boundary faces.

Main objects:

  libscalar_decomp::DistScalarTransportInputs
    std::vector<double> faceFlux
    std::vector<double> gammaFace
    std::vector<double> Su
    std::vector<double> Sp

  libscalar_decomp::DistScalarTransportOptions
    convectionScheme = upwind / central
    diffusionScheme  = orth / nonorth
    gradScheme       = lsq / gauss
    nNonOrthCorr
    solver = BiCGSTAB options

  libscalar_decomp::DistScalarTransportResult
    phi
    iterations
    finalRelRes
    nOuter
    globalNnz

Main solve:

  libscalar_decomp::DistScalarTransportResult solve_scalar_transport_decomp(
      const DecompMesh& dm,
      const DistScalarTransportInputs& in,
      const ScalarBCSet& bcSet,
      const DistScalarTransportOptions& opt,
      const std::vector<double>& x0 = {});

Linear solver backend:

  HYPRE ParCSR BiCGSTAB + HYPRE_ParCSRDiagScale / Jacobi.

This matches the desired SIMPLE momentum-solve style.

7. Scalar MMS equation and validation
================================================================================

Scalar MMS app:

  apps/scalar_transport_mms_decomp_gpu_mpi/

Equation solved:

  div(u phi) - div(Gamma grad(phi)) = S

Exact scalar:

  phi = sin(pi x) sin(pi y) sin(pi z)

Velocity:

  u = (1,0,0)

Diffusion:

  Gamma = 0.01

Source:

  S = u dot grad(phi) + 3 Gamma pi^2 phi

BC file used:

  /tmp/scalar_mms_cube.bc

Content:

  pressure patch_0_0 fixed_value 0.0

Note:
  The scalar MMS app maps pressure BC specs to scalar BCs for compatibility with the existing simple_gpu runtime BC parser.
  Later, a true scalar-specific config syntax can be added, but this is enough for the current modular flow.

9. What to do next: MPI simple_gpu / Stokes MMS
================================================================================

The next step should NOT be another two-machine test.

The next step should be building the actual decomposed SIMPLE/MPI app in a modular way using:

  libscalar_decomp  -> vector momentum/Stokes component solves
  libpoisson_decomp -> pressure correction / pressure Poisson solve
  DecompMesh        -> processor patches, off-rank columns, halos

Recommended first target is NOT full SIMPLE immediately.

Recommended first target:

  apps/stokes_mms_decomp_gpu_mpi/

or a staged mode inside:

  apps/simple_gpu_mpi/

that solves a Stokes MMS problem:

  -mu laplacian(U) + grad(p) = f
  div(U) = 0

Suggested MMS:

  u = sin(pi x)^2 * sin(2 pi y) * sin(2 pi z)
  v = sin(pi y)^2 * sin(2 pi z) * sin(2 pi x)
  w = sin(pi z)^2 * sin(2 pi x) * sin(2 pi y)

or use a simpler divergence-free manufactured vector field from a vector potential.

Pressure:

  p = sin(pi x) sin(pi y) sin(pi z)

Then source:

  f = -mu laplacian(U) + grad(p)

For the first implementation, it is okay to start with a known analytic velocity and pressure source to validate:
  - vector component scalar solves,
  - boundary velocity Dirichlet,
  - processor-face diffusion,
  - pressure-gradient source,
  - divergence calculation.

Then add pressure correction / SIMPLE-like iteration.

================================================================================
10. Required BC support for simple_gpu_mpi
================================================================================

The final MPI `simple_gpu_mpi` must keep the original modular BC idea.

Needed velocity BC types:

  1. wall no-slip:
       velocity patch wall_noslip

  2. fixed normal speed:
       velocity patch fixed_normal_speed <value> average_patch_normal

  3. fixed flow rate / uMean through patch:
       normal inlet velocity based on patch area/normal

  4. zero-gradient velocity:
       velocity patch zero_gradient

Needed pressure BC types:

  1. fixed value / Dirichlet:
       pressure patch fixed_value 0.0

  2. zero gradient / Neumann:
       pressure patch zero_gradient

  3. open/outlet variants if already present in original parser.

For Stokes MMS, the easiest first BC is:
  velocity patch_0_0 fixed_value_function/exact Dirichlet
  pressure patch_0_0 exact or pressure reference as needed

But for the pipe/SIMPLE case, preserve:
  wall patch_0_0 -> no-slip
  inlet patch    -> normal inlet velocity / flow rate
  outlet patch   -> pressure fixed_value 0 and velocity zero_gradient

Do not make `simple_gpu_mpi` a huge monolithic patch again.

Recommended architecture:

  1. Keep DecompMesh from libpoisson_decomp.

  2. Use libscalar_decomp for:

  3. Use libpoisson_decomp for:

  4. Add a thin FV-SIMPLE orchestration layer:
       - persistent fields U,V,W,p,pCorr
       - face flux phi
       - rAU / momentum diagonal extraction
       - Rhie-Chow face flux construction
       - pCorr solve
       - velocity correction
       - pressure update
       - convergence checks

  5. Processor-face versions must exist for:
       - velocity halo
       - pressure halo
       - rAU halo
       - gradP / gradPCorr halo
       - Rhie-Chow flux
       - velocity correction
       - divergence/mass residual

================================================================================
12. What is not performance-final yet
================================================================================

Both libpoisson_decomp and libscalar_decomp currently prioritize correctness and modularity.

Known performance limitations:

  - host-side assembly,
  - host IJ SetValues,
  - matrix recreation each solve,
  - no persistent HYPRE context reuse,
  - no GPU assembly kernels yet.

This is acceptable now.

The next goal is solver correctness and matching the serial SIMPLE algorithm.

Once the MPI SIMPLE logic is correct, optimize:
  - device assembly,
  - device IJ insertion,
  - persistent matrix pattern,
  - AMG reuse for pressure,
  - persistent BiCGSTAB/Jacobi context for momentum/scalar.
