Generic SIMPLE v2 potential/projection initial condition patch
==============================================================

Files changed
-------------
apps/generic_simple_v2/src/main.cu

New case-file / command-line options
------------------------------------
initMode uniform          # current behaviour: uniform inlet-average initial U
initMode potential        # new potential/projection initialisation

potentialInitRAU 1.0      # constant rAU used only during the initial projection
potentialInitMaxit 4000
potentialInitTol 1e-10
potentialInitRelTol 0
potentialInitWrite 0      # set 1 to write <outPrefix>_potential_init.vtu

Equivalent command-line options:
-init-mode potential
-potential-init-rAU 1.0
-potential-init-maxit 4000
-potential-init-tol 1e-10
-potential-init-reltol 0
-potential-init-write 0

What it does
------------
Before SIMPLE starts, the solver now optionally performs a single potential-style
projection:

1. Cell U is set to zero.
2. Boundary flux phiStar is built from the runtime velocity BCs.
3. A pressure/potential Laplacian is assembled with constant rAU.
4. potential is solved from div(phiStar).
5. U is initialised as -rAU*grad(potential), and the corrected face flux is computed.
6. The physical pressure p is kept at zero; the potential field is only a startup aid.

This is meant to mimic the useful role of OpenFOAM-style potential initialisation:
it gives SIMPLE a mass-consistent, boundary-driven starting velocity field instead
of asking the first momentum solve to create the entire flow from a weak/default
initial field.

Install / rebuild
-----------------
From the root of the existing anabasis_v0 tree:

  cd ~/anabasis_v0

  tar -xzf ~/Downloads/generic_simple_v2_potential_init_patch_bundle.tar.gz

  export PETSC_DIR=$HOME/src/petsc
  export PETSC_ARCH=arch-linux-cuda-opt
  export LD_LIBRARY_PATH="$PETSC_DIR/$PETSC_ARCH/lib:${LD_LIBRARY_PATH:-}"

  ./build_generic_simple_v2_direct.sh

Run examples
------------
Spiral / complex pipe style:

  cd ~/anabasis_v0
  mkdir -p runs/generic_simple_v2_spiral_potential
  mpirun -n 1 ./generic_simple_v2_direct \
    -case-config cases/spiral_generic_simple_v2_potential.case \
    -out-prefix runs/generic_simple_v2_spiral_potential/case \
    2>&1 | tee runs/generic_simple_v2_spiral_potential/run.log

Cylinder:

  cd ~/anabasis_v0
  mkdir -p runs/cylinder_generic_simple_v2_potential
  mpirun -n 1 ./generic_simple_v2_direct \
    -case-config cases/cylinder_generic_simple_v2_potential.case \
    -out-prefix runs/cylinder_generic_simple_v2_potential/case \
    2>&1 | tee runs/cylinder_generic_simple_v2_potential/run.log

Notes
-----
- This patch does not modify libpoisson or libscalar.
- The first version uses the existing pressure PCG/BoomerAMG infrastructure.
- If all pressure boundaries are Neumann, this still depends on the current app's
  pressure anchoring behaviour. Your usual inlet zeroGradient / outlet fixedValue
  cases are the intended target.
- If potentialInitWrite is 1, ensure the output directory already exists.
