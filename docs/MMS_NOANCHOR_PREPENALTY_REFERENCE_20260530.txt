ANABASIS MMS NO-POINT-ANCHOR PRESSURE REGULARIZATION REFERENCE
================================================================

Date: 2026-05-30

Main conclusion
---------------
The original single-precision MMS app was not fundamentally wrong in the finite-volume discretization, Rhie-Chow construction, LSQ gradients, subtri flux reconstruction, or non-orthogonal handling.

The MMS pressure convergence issue came from the local pressure reference-cell anchor used for all-Neumann/manufactured pressure equations.

For MMS/all-Neumann pressure:
  Bad:
    local point pressure anchor/reference cell

  Good:
    disable point anchor
    add distributed pre-AMG pressure penalty to the pressure matrix
    add matching beta*p_exact term to RHS in MMS mode

For physical cylinder/outlet benchmark cases:
  If pressure outlet is fixed_value 0, the pressure nullspace is already physically removed.
  Use simpleMmsPressurePenaltyCoeff 0.
  Do not use the penalty for production force validation.

For polyhedral convergence, compute mesh size using:
  h_eff = (bbox_volume / nCells)^(1/3)

Do not use folder name alone for polyhedral order calculations.

Observed SP polyhedral convergence over 16cube->81cube using h_eff:
  Velocity order approximately 2.52
  Pressure order approximately 2.00
